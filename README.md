# kiki-delivery-game-in-js
Goal: Catch the strawberries with the basket without crashing into flying bees. Complete all 3 levels to win the game.\

Controls:\
[Up Arrow] move up\
[Down Arrow] move down\
[Left Arrow] move left\
[Right Arrow] move right\

Requirements:\
- You will need a browser with internet to play the game.\

This game was written with JavaScript and HTML by Michelle Chan.\
